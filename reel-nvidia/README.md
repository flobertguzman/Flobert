# Reel: renuncia de Jensen Huang (Nvidia)

Reel vertical de 38,5 s (1080×1920, 30 fps) hecho con Remotion, con voz en off y cierre con el logo de HEAVY.

- Ver y editar: `npm run dev`
- Renderizar: `npx remotion render Reel out/reel-nvidia.mp4`
- Logo del cierre: `public/logo-heavy.png` (convertido del .ai original); se activa en `src/theme.ts` (`BRAND.logo`).
- Duración de cada escena: `SCENES` en `src/theme.ts`.
- Sonidos: Kenney (CC0), ver `public/sfx/CREDITOS.txt`.

Datos al 12/11/2026. Fuentes: comunicado y 8-K de Nvidia, The New York Times, CNN, CNBC, Yahoo Finance.
